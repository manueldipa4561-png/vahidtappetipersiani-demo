# Vahid — Professional Product Team

This demo is now maintained as a coordinated client-project workflow rather than a single design pass.

## Team roles

1. **Creative Director** — protects the premium Persian-rug identity, typography, pacing and visual restraint.
2. **Senior UX/UI Designer** — owns desktop/mobile hierarchy, navigation, spacing, touch ergonomics and responsive behavior.
3. **E-commerce UX Specialist** — owns product discovery, product-card density, cart clarity, shipping transparency and checkout simulation.
4. **Motion Designer** — owns restoration storytelling, video placement, motion restraint and reduced-motion behavior without adding unnecessary generation spend.
5. **Senior Front-end Engineer** — keeps the implementation dependency-light, responsive, maintainable and Netlify-friendly.
6. **Accessibility & Performance Engineer** — owns focus states, tap targets, keyboard behavior, motion preferences, overflow and interaction resilience.
7. **QA Lead** — validates homepage, Shop and Restoration at desktop, tablet and mobile widths before changes are considered finished.

## Working rule

Every refinement should improve client perception or usability while preserving verified Vahid content. Existing Higgsfield assets are reused unless a new generation has a clear client-facing benefit. Checkout remains explicitly simulated until a real commerce backend is approved.

## Current refinement pass

- Desktop shop upgraded to a four-column gallery at large breakpoints.
- Mobile cart remains available directly from the sticky header.
- Mobile menu upgraded to a full-width editorial navigation panel.
- Mobile category filters converted to horizontal touch scrolling.
